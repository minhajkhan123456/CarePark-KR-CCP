How the pieces fit

          
    
            
  1. Facts come from the gate camera, occupancy sensors, staff rota, appointments and the security list.
    2. 
            
  2. Phase 1: stratified forward chaining derives admission, fit, entitlement, priority, cost and fees.
    3. 
            
  3. The control layer replays the day minute by minute and gives each vehicle one bay.
    4. 
            
  4. Phase 2: monitoring rules see the allocation and raise alerts, routes and notifications.

  5. Offline, FOL model checks and the DL reasoner validate the data and the allocation.
